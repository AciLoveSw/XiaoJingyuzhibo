# 小鲸鱼直播套装 · 使用说明

这是一个可以「自己开播」的 AI 虚拟主播。

## 你会得到什么

一个人物站在直播间里，观众发弹幕她能看见、能回答、能说话、能念礼物，还会翻跟头跳舞。

## 怎么用（三步）

### 第一步：把这个文件夹发给 AI

打开你常用的 AI（DeepSeek / 豆包 / 通义都行），把整个文件夹拖进去，说：

> 「按 给AI的搭建说明.md 帮我搭好」

AI 会带你装环境、配 OBS、调弹幕识别。**跟着它做就行，不需要懂代码。**

### 第二步：准备两个钥匙

| 要什么 | 去哪拿 | 大概花多少 |
| --- | --- | --- |
| 大模型 Key | platform.deepseek.com 注册 | 充 10 块能播很久 |
| OBS 密码 | OBS → 工具 → WebSocket 服务器设置 | 免费 |

填进 `config.json` 就行，AI 会教。

### 第三步：开播

双击 `开播.bat` → OBS 点「启动虚拟摄像头」→ 直播伴侣点「开始直播」。

## 电脑要装什么

- Windows 10 / 11
- Python 3.10 以上
- OBS Studio（免费）
- 抖音直播伴侣（PC 版）

## 三条必须知道的规矩

1. **发作品要勾「内容由 AI 生成」**，这是硬性要求。
2. **开播时直播伴侣要放前台**，弹幕是靠读屏识别的，被挡住就读不到。
3. **不能挂着不管**——抖音会判「非实时直播」封禁。前 10 分钟一定要盯一下。

## 文件夹里都有什么

| 文件 | 说明 |
| --- | --- |
| 给AI的搭建说明.md | **交给 AI 的那份**，里面有全部技术步骤 |
| 运营\运营手册.md | 账号怎么做、发什么内容、怎么涨粉 |
| 运营\发布文案模板.md | 发作品时照着填 |
| 开播.bat | 一键启动 |
| config.json | 填 Key 的地方 |
| 其余 .py / .html | 程序本体，不用动 |

## 大概要花多少

| 项 | 费用 |
| --- | --- |
| Python / OBS / 直播伴侣 | 0 |
| 语音合成（edge-tts） | 0 |
| 大模型 | 一场 3 小时约 0.5~2 元 |
| 形象（现在这套是现成的） | 0 |
| 想换成自己的形象（Live2D） | 300~800 定制 |

## 出问题了怎么办

把现象告诉 AI，比如：

- 「画面里没有人物」
- 「直播伴侣显示无信号」
- 「弹幕读不到」

`给AI的搭建说明.md` 第 10 节有完整的排查表，AI 一看就知道怎么修。
