# 发布文案模板

> 每次发作品，把下面四块填好就能发。

---

## 一、标题

**模板**：`[具体场景] + [反差/结果]`

合格例子：

- AI 主播第一次开播，3 分钟就被平台封了
- 她念错了一个字，观众刷了 40 条笑她
- 播了 3 小时，29 个人看了我 3 分钟

不合格（不要用）：

- AI 主播 7 天复盘 ❌（没有场景）
- 我的虚拟主播上线了 ❌（没有反差）

---

## 二、正文

**结构**：结论 → 细节 → 转折 → 行动

```
[一句话说清发生了什么]

[给一个具体数字或细节]

[最难堪/最意外的那一下]

[我怎么处理的 / 下一步做什么]
```

**写法要求**：

| 要       | 不要       |
| ------- | -------- |
| 短句，一行一句 | 大段文字     |
| 真实数字    | 「很多」「一些」 |
| 自嘲      | 诉苦、卖惨    |
| 具体动作    | 空泛感悟     |

---

## 三、话题

3~5 个，**第一个最重要**。

```
#AI主播 #虚拟主播 #抖音直播 #AI生成
```

根据内容换：

| 内容类型 | 话题                 |
| ---- | ------------------ |
| 直播相关 | #AI主播 #虚拟主播 #抖音直播  |
| 数据复盘 | #自媒体 #涨粉 #直播复盘     |
| 技术相关 | #AI #大模型 #DeepSeek |

---

## 四、首评（自己发，很重要）

**作用**：评论区第一条会被很多人看到，用它抛问题。

**模板**：

```
说真的，[一句自嘲或感受]。
你们觉得[一个开放问题]？评论区告诉我。
```

例子：

> 说真的，29 个观众里有 4 个人愿意打字，我已经很感动了。  
> 你们觉得 AI 主播最大的问题是什么？评论区告诉我，我一条条改。

**注意**：问题要**具体、好回答**。不要问「你们觉得怎么样」。

---

## 五、发布检查清单

发之前对一遍：

- [ ] 标题是**具体场景**，不是总结词
- [ ] 正文有**至少一个真实数字**
- [ ] 勾选了 **「内容由 AI 生成」**
- [ ] 话题 3~5 个
- [ ] 首评已准备好，发布后 1 分钟内发
- [ ] 封面第一页能让人看懂「这条在讲什么」

---

## 六、配图规范

| 项  | 要求                       |
| -- | ------------------------ |
| 尺寸 | 1080 × 1440（竖屏 3:4）      |
| 张数 | 5 张（少于此数不易完整表达）          |
| 字体 | 微软雅黑 Bold                |
| 主色 | 蓝 #4A7BD0                |
| 每页 | 右下角标 `01 / 05` 页码        |
| 角标 | 左下 `@账号名`，右下 `内容由 AI 生成` |

**避免同质化**（这是最容易犯的错）：

- 不要每页都是「标题居中 + 人物居中」
- 每页换构图：左对齐 / 数字宫格 / 倾斜卡片 / 时间轴 / 大半身
- 人物姿势也换：镜像、只露头、旋转贴纸、出框
