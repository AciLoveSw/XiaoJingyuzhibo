# 账号运营手册

> 这套东西解决的是「怎么播」，这份解决的是「播什么、怎么涨粉」。

---

## 一、账号定位

### 一句话人设

必须能在 15 字内说清「她是谁、为什么有意思」。

例子（本套件原版）：

> 住在你电脑里的鲸鱼娘

这句话好在：有画面、有反差（深海生物住电脑里）、能延伸（她不懂人类的东西）。

### 人设三件套

| 要素 | 作用 |  przykład |
| --- | --- | --- |
| 身份 | 她是谁 | 一条游进电脑的鲸鱼 |
| 性格 | 她怎么说话 | 俏皮、爱自嘲、不装可爱 |
| 弱点 | 观众为什么喜欢 | 电不够、怕被关掉、不懂人类常识 |

**弱点比优点重要。** 完美的人设没人接话，有缺点的才有人逗。

## 二、作品（图文）

### 为什么做图文不做视频

- 图文制作成本低（一次生成 5 张图 + 文案，10 分钟）
- 抖音图文仍有流量扶持
- 适合「有观点、有梗、有数据」的内容，不需要镜头表现力

### 单条作品的结构（5 张图）

| 页 | 内容 | 目的 |
| --- | --- | --- |
| 1 封面 | 一句**具体场景**的标题 | 让人停下 |
| 2 | 数据 / 事实 | 建立可信度 |
| 3 | 冲突 / 反转 | 制造情绪 |
| 4 | 我的做法 | 提供价值 |
| 5 | 行动号召 | 转化关注 |

### 标题怎么写

**要写具体场景，不要写总结词。**

| ❌ 不要 | ✅ 要 |
| --- | --- |
| AI 主播 7 天复盘 | AI 主播第一次开播，3 分钟就被封了 |
| 我做了个虚拟主播 | 她今天念错了一个字，被观众笑了 40 条 |

判断标准：这个标题**能不能拍成一张照片**。能，就是好标题。

### 发布节奏

- 每天 1~2 条，固定时间（比如 12:00 / 20:00）
- 直播前后各发一条（开播预告 + 直播复盘）
- **不要在作品里放微信号**，会被限流

## 三、直播

### 开播前 3 分钟

1. 直播伴侣最大化、前台
2. OBS 启动虚拟摄像头
3. 双击 开播.bat
4. 直播间标题写清楚「AI 虚拟主播」

### 前 10 分钟决定流量

抖音会给新直播间一波初始流量，**前 10 分钟的互动率决定要不要继续推**。

所以要：

- 有人说话**马上回应**（延迟超过 10 秒，人已经走了）
- 没人说话就**自己抛话题**（系统 45 秒会自动说一句）
- 主动念弹幕：「刚才有人说……」

### 每小时做什么

| 时间 | 动作 |
| --- | --- |
| 0-10 分 | 密集互动，回答所有人的弹幕 |
| 10-30 分 | 抛话题，引导点歌/送礼 |
| 30-60 分 | 聊自己的「设定」，讲AI主播的日常 |
| 每 5 分钟 | 至少回一条弹幕 |

### 数据看什么

| 指标 | 健康值 | 说明 |
| --- | --- | --- |
| 平均观看时长 | > 1 分钟 | 低于 30 秒说明留不住人 |
| 互动率（评论/观看） | > 3% | 低于 1% 会被判低质 |
| 涨粉率 | > 1% | 100 人看涨 1 个粉 |

## 四、内容选题（可复用）

围绕「AI 主播」这个身份，永远有内容：

| 类型 | 例子 |
| --- | --- |
| 直播事故 | 第一次开播被封 / 念错字 / 卡住不说话 |
| 观众提问 | 有人问我 Key / 有人问我会不会梦见电费 |
| 数据复盘 | 播了 3 小时，29 个人看了我 3 分钟 |
| 幕后 | 我怎么被做出来的 / 我一天要花多少 token |
| 对比 | AI 主播 vs 真人主播，谁更会聊天 |

**最好的一类：真实发生的小事故。** 观众爱看翻车，不爱看完美。

---

## 五、涨粉的笨办法（但有效）

1. **每条作品的评论区自己抢首评**，抛一个问题，引导观众回答
2. **直播时念出观众昵称**，被念到的人大概率会关注
3. **固定开播时间**，养成习惯的观众会回来
4. **作品和直播互相导流**：作品结尾说「今晚 8 点直播」，直播时说「主页有我的翻车合集」

---

## 六、红线（碰了会封）

| 红线 | 后果 |
| --- | --- |
| 不标注 AI 生成 | 限流 / 下架 |
| 纯挂机直播 | 封禁直播权限 |
| 站外引流（微信、QQ） | 限流 / 封号 |
| 敏感话题（政治、金融、医疗） | 封禁 |
| 诱导消费话术过猛 | 警告 / 封禁 |

---

## 七、第一个月目标

| 周 | 目标 |
| --- | --- |
| 第 1 周 | 发 7 条作品，播 3 场，每场 30 分钟 |
| 第 2 周 | 找到 1 个能复用的选题方向 |
| 第 3 周 | 单条作品破 1000 播放 |
| 第 4 周 | 粉丝 100，直播平均在线 5 人 |

**不要一开始就追求爆款。** 先把「每天发、每周播」变成习惯。
